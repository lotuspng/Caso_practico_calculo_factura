Este programa calcula totales en base a cantidad y precio de producto individual, si este pasa de 5,000 se produce un 10% de descuento
datos de entrada:
cantidad de objetos
precio de objetos
datos procesados:
precio de objetos
cantidad de objetos
datos de salida:
total (sin descuento)
total (con descuento)







Criterio de uso: usé multiplicación ya que era la herramienta mas eficiente, el programa multiplica las primeras dos variables y luego genera una tercera en base al resultado, el cual se ve afectado por una condicional que actúa si el precio va por encima de los 5,000, multiplicar por 0.9 es el mismo resultado que sacar y restar el 10% , ahorrando tiempo por la vía mas simple.
